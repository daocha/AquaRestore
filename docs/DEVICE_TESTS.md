# 裝置驗證清單

單元測試涵蓋推薦方向、低信心、影片異常樣本穩健性、強度 0／50／100%、alpha、直式尺寸與 Original 位元率。編譯與單元測試不等同於真機編解碼驗證。

## 必測素材

- 1080p30 H.264、4K60 HEVC、直式 1080×1920、29.97fps、可變幀率、有／無音軌。
- 偏藍海水、偏綠海水、淺水自然色、暗部、過曝反光、多場景剪接。
- 帶 EXIF 旋轉的 JPEG、透明 PNG、大尺寸 48MP 照片。
- HDR10／PQ、HLG：Android 13+ 且具 HDR 編碼能力的真機應保留 BT.2020、10-bit 與來源曲線；不支援的裝置明確提示，禁止自動 SDR 降級。Dolby Vision／已標識 HDR10+ 應提示動態 metadata 尚不支援。

## 操作驗證

1. 匯入：六點樣本產生建議，暗部信心提示；分析後立即可播放與調整，不需等待轉檔；再次匯入不出現上一份結果。
2. 播放：拖動強度及進階滑桿，確認不重啟播放；暫停時調色／對比也應更新靜止影格。
3. 比較：原色及校正切換時時間軸保持連續；強度 0 是原色。
4. 匯出：Original 對照來源尺寸、音軌同步、rotation、時間戳、位元率及 codec。來源不支援的編碼器不得偷偷降低畫質。
5. 自訂：橫直片各測 960／1920，24／30 fps，低高 quality，JPEG／PNG、尺寸與圖片方向。
6. 生命週期：旋轉螢幕、背景／回前景、匯出時熄屏、服務通知取消。取消後相簿不留下半成品。
7. 錯誤：儲存空間不足、撤銷來源權限、壞檔案、不支援編碼；App 不崩潰，有提示。
8. 中英／淺深色／跟隨系統設定，重新開啟後偏好保持；小螢幕及大字體可捲動。

## 性能評估

在至少一台中階與一台旗艦手機測直接播放原始影片的預覽（1080p、4K30）與 4K60 的背景代理切換。記錄連續 60 秒 dropped frames、UI frame time、溫度及記憶體；確認代理完成後切換時位置不跳動、不出現錯誤。驗證 4K 匯出不走代理、調色結果接近預覽。真機不支援來源 codec 的 Original 應明確失敗，自訂 H.264 可再嘗試。

## 新增互動與變速驗收

- 展開進階調整，滑到陰影並持續拖動，預覽應一直可見且更新；另測小螢幕、橫向及大字體。
- 按住對比顯示原色，鬆開、拖出或系統取消觸控後恢復。
- 比較 0%、85%、100%、200% 的圖片與影片，確認進階基礎數值不被覆寫。
- 0.5×／2×／4× 預覽、Original 與自訂 fps 匯出；檢查長片口型、音高、時長、無音軌素材及高 fps 編碼器限制。
